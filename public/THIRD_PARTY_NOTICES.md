# 第三方依赖与参考

## 功能参考：PeerTube

功能与产品思路参考 [PeerTube](https://joinpeertube.org/)（[源码](https://github.com/Chocobozzz/PeerTube)），未使用其源码，不是其分支、衍生发行版或兼容客户端，也不实现其 API、ActivityPub 或 P2P 协议。与 PeerTube、Framasoft 无官方关联或背书。MIT 授权不适用于 PeerTube 代码；未来引入其代码须遵守对应版本许可证。

## 依赖

- Next.js — MIT — https://github.com/vercel/next.js
- React / React DOM — MIT — https://github.com/facebook/react
- Lucide — ISC — https://github.com/lucide-icons/lucide
- TypeScript — Apache-2.0 — https://github.com/microsoft/TypeScript
- @types 类型包 — MIT — https://github.com/DefinitelyTyped/DefinitelyTyped

具体版本及间接依赖以 package-lock.json 为准。第三方组件按各自许可证使用，分发时保留必要的版权及许可声明。`public/third-party/` 保留浏览器运行依赖的许可证副本。

## 素材

`public/posters/` 为本仓库生成的原创几何 SVG；播放器为 Canvas 几何动画，随本项目按 MIT 提供。目录、评分、分集均为虚构示例。未复制原工程的第三方海报、影片、品牌图片或研究截图。
